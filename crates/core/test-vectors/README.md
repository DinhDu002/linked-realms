# Test vectors

`tests/vectors.rs` checks every file here. TypeScript tests read `identity.json` too; from step 2C item 10 they read `chain.json` as well.

| File | What | Source |
|---|---|---|
| `identity.json` | Our own profile (`docs/protocols/identity.md`): words, BIP-39 seed, `xi`, public key and address for several entropies and indexes, one signed statement per context, and one invalid address per rejection rule | Generated by `tests/vectors.rs` with `UPDATE_VECTORS=1`. Regenerate only on purpose: a change means new keys and addresses for everyone. |
| `chain.json` | Our own chain rules (ADR 0011): network ids, address bytes (valid and refused), Block rewards at the era edges and the total before the tail reward, and `tx_root` for 0 to 5 and 8 ids. Later items of step 2C add transactions, the state root, the Retarget, headers and Blocks | Generated by `tests/vectors.rs` with `UPDATE_VECTORS=1`. Regenerate only on purpose: a change is a change of the chain's rules. |
| `nist-ml-dsa-44-keygen.json` | ML-DSA-44 `KeyGen_internal`: 25 seeds and their public keys | NIST ACVP-Server, `gen-val/json-files/ML-DSA-keyGen-FIPS204/{prompt,expectedResults}.json`, test group 1, commit `975de31eb83d87039ec88934fdc47d8c312b892d`. Private keys omitted. |
| `nist-ml-dsa-44-sigver.json` | ML-DSA-44 verification, external interface, pure: 15 cases, valid and invalid | NIST ACVP-Server, `gen-val/json-files/ML-DSA-sigVer-FIPS204/{prompt,expectedResults}.json`, test group 1, same commit. |
| `bip39.json` | BIP-39 English vectors with 32 bytes of entropy; seeds use the passphrase `TREZOR` | `trezor/python-mnemonic` `vectors.json`, commit `b57a5ad77a981e743f4167ab2f7927a55c1e82a8` (MIT licence). |
