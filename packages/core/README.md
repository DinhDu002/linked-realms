# @linked-realms/core

The WebAssembly build of `crates/core`: ML-DSA-44 keys, signatures and addresses (`docs/protocols/identity.md`, ADR 0009), and transactions and amounts (`docs/protocols/transactions.md`). The Shell, `hub-api`, the relay and the reference Map server all use it, so there is one implementation (P9).

- `pnpm --filter @linked-realms/core build` runs `cargo build --features wasm --target wasm32-unknown-unknown --profile wasm`, then `wasm-bindgen --target web` into `pkg/` (not committed). Turbo runs it before any `typecheck` or `test` that needs it. It needs the Rust toolchain from `rust-toolchain.toml` and `wasm-bindgen-cli` 0.2.129 (`cargo install wasm-bindgen-cli --version 0.2.129 --locked`).
- In Node, importing the package loads the module synchronously. In browsers, await `ready` first.
- `sign` takes `rnd`, 32 fresh random bytes from the caller (`crypto.getRandomValues`), because `wasm32-unknown-unknown` has no random source. Call `free()` on a `Key` when done, or declare it with `using`, so its private key is wiped.
- Transactions: `Key.signTransfer` and `Key.signRotation` build and sign one for a network id (`1` the test network, `2` the dev network; any other is refused) and return its bytes; `transactionId` gives the id of any transaction's bytes on a network. `withPublicKey` adds the signer's own public key, which the sender's first transaction must carry; the sender is passed apart from the key, since after a rotation the address stays and the key changes. Nonces, fees and amounts are base units, as `bigint`. They refuse what no Node would take on its format (a memo over 80 bytes, a new key of the wrong length); the account rules (nonce, balance, the first transaction's key) are the Node's. `parseAmount` and `formatAmount` turn GOLD as typed into base units and back; `addressToBytes` and `addressFromBytes` give an address's 34-byte payload. `chain.test.ts` builds the vectors' transactions again byte for byte.
- Every integer argument (a network id, a scheme, a Character index, a nonce, a fee, an amount) is refused out of range, never taken modulo 2^bits as wasm-bindgen's own integer arguments would take it (`-1n` as the nonce 2^64 - 1).
- Size on 2026-10-31: `linked_realms_core_bg.wasm` is 211 KB, 77 KB with gzip and 63 KB with Brotli (190, 68 and 55 KB on 2026-10-29, before the transaction API).
