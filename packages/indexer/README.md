# @linked-realms/indexer

Ponder indexer: turns `PlayerRegistry` and `Land` events into `character`, `character_stat` and `land` tables, served as GraphQL (`/graphql`) and Ponder's SQL client endpoint (`/sql/*`).

## Run

Start PostgreSQL (`docker compose up -d`) and anvil with the contracts deployed (`packages/shared/src/deployments/31337.json`), then:

```bash
DATABASE_SCHEMA=indexer pnpm --filter @linked-realms/indexer start   # or `dev`
```

`start` requires `DATABASE_SCHEMA` (or `--schema`); `dev` defaults to `public`. The API listens on port 42069 (`--port` to change): `http://localhost:42069/graphql`.

| Env var            | Default                                                           |
| ------------------ | ----------------------------------------------------------------- |
| `CHAIN_ID`         | `31337` (must exist in `deploymentFor`)                           |
| `PONDER_RPC_URL`   | `http://127.0.0.1:8545`                                           |
| `DATABASE_URL`     | `postgres://linked_realms:linked_realms@127.0.0.1:5432/linked_realms` |
| `DATABASE_SCHEMA`  | none for `start`                                                  |

`ponder-env.d.ts` is generated by `pnpm --filter @linked-realms/indexer codegen`; commit it, do not edit it.
