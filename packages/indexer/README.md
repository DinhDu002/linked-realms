# @linked-realms/indexer

Ponder indexer: turns `PlayerRegistry`, `Land` and `GoldMine` events into `character`, `character_stat`, `land`, `round_won` and `retarget` tables, served as GraphQL (`/graphql`) and Ponder's SQL client endpoint (`/sql/*`).

## Run

Start PostgreSQL (`docker compose up -d`) and anvil with the contracts deployed (`packages/shared/src/deployments/31337.json`), then:

```bash
DATABASE_SCHEMA=indexer pnpm --filter @linked-realms/indexer start   # or `dev`
```

`start` requires `DATABASE_SCHEMA` (or `--schema`); `dev` defaults to `public`. The API listens on port 42069 (`--port` to change): `http://localhost:42069/graphql`.

| Env var            | Default                                                           |
| ------------------ | ----------------------------------------------------------------- |
| `CHAIN_ID`         | `31337` (must exist in `deploymentFor`)                           |
| `PONDER_RPC_URL`   | `http://127.0.0.1:8545`                                           |
| `DATABASE_URL`     | `postgres://linked_realms:linked_realms@127.0.0.1:5432/linked_realms` |
| `DATABASE_SCHEMA`  | none for `start`                                                  |

`ponder-env.d.ts` is generated by `pnpm --filter @linked-realms/indexer codegen`; commit it, do not edit it.

## Mine tables

- `round_won`: one row per won Round (`round` key, `reward_wallet`, `submitter`, `nonce`, `reward`, block, timestamp, `transaction_hash`).
- `retarget`: one row per Retarget (`round` key, `old_target`, `new_target`, `actual_seconds`, block, timestamp).

Rounds won by one wallet (SQL, `/sql/*`):

```sql
SELECT round, reward, timestamp FROM round_won
WHERE reward_wallet = '0x...' ORDER BY round DESC;
```

GraphQL:

```graphql
{
  roundWons(where: { rewardWallet: "0x..." }, orderBy: "round", orderDirection: "desc") {
    items { round reward timestamp transactionHash }
  }
}
```
